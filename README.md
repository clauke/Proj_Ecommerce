# 🛒 Projeto E-commerce – Analytics interativo com Dash e Plotly  

## 📊 Sobre o projeto  

No contexto de e-commerce, decisões comerciais dependem da capacidade de responder perguntas como:

- Quais produtos e categorias geram mais receita?  
- Como as vendas evoluem ao longo do tempo?  
- Onde estão as principais oportunidades de crescimento?  
- Como diferentes segmentos impactam o faturamento?  

Este projeto tem como objetivo transformar dados de vendas em **insights claros e interativos**, apoiando a análise e a tomada de decisão.

---

## 🔁 Pipeline de dados  

O projeto foi desenvolvido contemplando as etapas de:

- Leitura e tratamento do dataset (*Superstore*)  
- Limpeza e organização dos dados  
- Análise exploratória  
- Criação de métricas de negócio  
- Desenvolvimento de aplicação interativa  

---

## 📈 Análises realizadas  

Foram exploradas análises voltadas ao contexto comercial, como:

- Faturamento ao longo do tempo  
- Desempenho por categoria e subcategoria  
- Volume de vendas  
- Segmentação de clientes  
- Identificação de padrões e tendências  

---

## 💻 Aplicação interativa  

O projeto conta com uma aplicação desenvolvida com **Dash e Plotly**, permitindo:

- Navegação dinâmica pelos dados  
- Filtros interativos  
- Visualizações analíticas em tempo real  
- Exploração intuitiva das informações  

O uso de **HTML e CSS** contribui para a organização e apresentação da interface.

---

## 🛠️ Tecnologias utilizadas  

- Python  
- Pandas  
- Dash  
- Plotly  
- HTML  
- CSS  

---

## 🎯 Objetivo  

Mais do que apresentar gráficos, este projeto busca:

> Transformar dados de vendas em uma experiência interativa de análise, permitindo explorar informações e apoiar decisões no contexto de e-commerce.

---

## 📂 Dataset  

Os dados utilizados neste projeto são provenientes do dataset **Superstore**, amplamente utilizado para análises de vendas e aprendizado em Data Analytics.
